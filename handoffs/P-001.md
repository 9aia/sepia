# Handoffs — P-001

## 2026-11-18 · human:Luis-Emidio
Framing refinement — sepia already abstracts TWO layers; this proposal
is the runtime half of a symmetry that already exists:

CONFIG IR (exists today — sepia-core agent_config.rs, `sepia config`,
tamias-driver-sepia-config packs): portable DEFINITIONS of skills,
rules, commands (slash-command defs + prompt templates), hooks
(canonical events → per-agent wire names), subagents, MCP servers —
one canonical IR installed into devin/cline/claude/cursor.

SESSION PLANE (this proposal): live-session MECHANISM — and
`sessions.commands`/`sessions.command` is the runtime counterpart of
the config IR's `ConfigCommand`: config defines what commands an
agent SHOULD have; the session op invokes what the live session
actually advertises (availableCommands, capability-discovered).

Same pattern repeats for hooks (config installs them; session events
surface their firing) and MCP (config installs servers; session tool
calls exercise them). The abstraction is complete when definition
and invocation are both agent-agnostic — P-001 closes the invocation
gap for the command family.

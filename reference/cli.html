On this page

CLI and environment ​

The sepia command's surface and the environment variables the plane reads. sepia --help is authoritative; this page is the map.

There is no hand-rolled sepia binary: the command ships as the tamias pack in libraries/sepia/ — a generated bins[] shim that runs tamias-driver-sepia cli → sepia_cli::run_from in-process (T-012). Every verb below behaves identically through the shim.

Commands ​

Top-level store verbs are aliases for the store namespace — sepia list ≡ sepia store list, and so on.

CommandWhat it does
sepia driver list [--json]Discovery: the sepia-driver-* binaries found, their probed manifests, and whether each agent command resolves. sepia driver alone lists them.
sepia listList sessions in a store (store list).
sepia export <id> [out] [--format json|cline]Session IR JSON to stdout/a file; --format cline writes Cline session files instead (out is then a directory).
sepia import <source> [--to <agent>] [--session-id <id>] [--force]Import a Cline session dir, a Claude .jsonl transcript, or a session JSON export into a store.
sepia install <id> [--from <a>] [--to <b>] [--id <id>] [--force]Copy a session into a store ready to resume — cline (default), claude, cursor, or devin.
sepia delete <id> [--from <agent>]Delete a session from a store.
sepia config list|export|import|install|diffAgent config IR ops — rules/skills/commands/hooks/subagents/MCP. See agent configs.
sepia serveThe session plane — ndjson JSON-RPC on stdio. See serve wire.
sepia versionVersion stamp.

Store flags (--devin-dir, --claude-dir, --cursor-dir, --cline-dir) pick the store directory and imply the agent when --from/--to is omitted.

The driver ops surface ​

tamias-driver-sepia doubles as the generated-surface driver (P-021). ops answers an ops manifest derived from the clap tree: every bounded verb is a cli.<verb> wire query — driver, list, export, import, install, delete, config, version and friends, 18 ops total — dispatched through sepia_cli::run_from in a captured child. run <argv> is the raw passthrough; cli <argv> is the bins[] shim verb the sepia command itself execs (inherited stdio, so sepia serve streams end-to-end). serve is listed under surfaces, never an op — it never returns. A feature-gated mcp mode renders the same manifest as MCP tools via pavo-driver-kit.
